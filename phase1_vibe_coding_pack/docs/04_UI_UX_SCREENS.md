# 04 — UI/UX Screens

## Design direction
Use a premium biotech SaaS interface.

Visual keywords:
- Clean clinical dashboard
- White, soft green, soft blue
- Glassmorphism cards
- Rounded panels
- Calm scientific credibility
- Minimal icon use
- Clear evidence badges

Avoid:
- Overly futuristic purple AI look
- Cartoon medical claims
- Patient diagnosis visuals
- Red emergency/hospital styling
- Overcrowded tables

## Screen 1 — Landing / Dashboard

### Purpose
Explain the product in one glance.

### Content
Hero text:
> From mutation data to drug-repurposing shortlist — faster.

Subtitle:
> BioQuantum Oncology helps oncology R&D teams rank mutation-risk signals and repurposable drug hypotheses from de-identified genomic datasets.

Primary button:
> Run Demo Analysis

Secondary button:
> View Architecture

Metric cards:
- Research-use platform
- Mutation ranking
- Drug repurposing shortlist
- Explainable evidence report

Disclaimer card:
> Research-use only. Not for diagnosis or treatment recommendation.

## Screen 2 — Dataset Upload / Selection

### Purpose
Show how the researcher starts.

### UI elements
- Upload area
- Demo dataset button
- Dataset summary card
- Analysis goal checklist

Analysis goals:
- Mutation relevance ranking
- Cancer pathway mapping
- Drug-repurposing shortlist
- Evidence report

Dataset summary example:
- Cancer type: Lung adenocarcinoma demo
- Samples: 48 de-identified records
- Genes detected: EGFR, TP53, KRAS, ALK, BRCA1
- Status: Ready for research analysis

## Screen 3 — Analysis Progress

### Purpose
Make the AI/quantum workflow visible.

### Steps
1. Standardising mutation fields
2. Mapping genes to cancer pathways
3. Ranking mutation relevance
4. Matching drug-target relationships
5. Running hybrid ranking layer
6. Building explainable report

Each step should show a completed/pending state.

## Screen 4 — Mutation Ranking Results

### Purpose
Show the first output: important mutations.

### Components
- Top findings summary
- Ranked mutation table
- Pathway distribution chart
- Confidence badges

Columns:
- Rank
- Gene
- Mutation
- Pathway
- Evidence
- AI confidence
- Interpretation

Example interpretation:
> EGFR L858R is a known oncogenic driver in lung adenocarcinoma and is relevant for targeted therapy research.

## Screen 5 — Drug-Repurposing Shortlist

### Purpose
Show business value: candidate prioritisation.

### Components
- Top 5 candidate cards
- Final score
- Drug class
- Matched pathway
- Evidence badge
- “Why ranked?” button

Important label:
> These are research hypotheses, not treatment recommendations.

## Screen 6 — Explainability Panel

### Purpose
Defend trust and scientific credibility.

### Sections
- Matched mutation/pathway
- Drug-target logic
- Evidence category
- Confidence factors
- Limitations
- Next validation step

Example:
> This drug is ranked because its known target is connected to the EGFR pathway detected in the uploaded mutation profile. The ranking combines mutation relevance, pathway match, drug-target evidence, and a prototype quantum-inspired compatibility score.

## Screen 7 — Report Preview

### Purpose
Show what the customer receives.

### Sections
1. Dataset summary
2. Top mutation-risk signals
3. Top drug-repurposing candidates
4. Evidence notes
5. Limitations
6. Recommended validation steps
7. Research-use disclaimer

CTA:
> Export Research Report

## Screen 8 — Architecture / About IP

### Purpose
Explain how UM IP is applied meaningfully.

### Flow diagram
```text
Genomic dataset
→ Classical preprocessing
→ AI mutation engine
→ Drug-target knowledge layer
→ Hybrid quantum-classical ranking
→ Explainable research report
```

### Message
> The UM IP is used as the protected hybrid AI-quantum analytics workflow for mutation detection, cancer risk signal ranking, and drug-repurposing prioritisation.
