# Phase 1 Acceptance Checklist

Use this before showing the prototype to mentors or judges.

## Product clarity

- [ ] The product name is consistently OncoQ.tech.
- [ ] The homepage/dashboard explains the value proposition in one glance.
- [ ] The main headline says mutation data becomes a drug-repurposing shortlist.
- [ ] The target customer is clearly research teams / genomics labs / R&D teams.
- [ ] The product is not framed as a consumer patient app.

## Research-use safety

- [ ] Every page avoids clinical treatment recommendation language.
- [ ] A research-use disclaimer is visible.
- [ ] Outputs are labelled as research hypotheses.
- [ ] There is no “recommended treatment” wording.
- [ ] There is no “diagnosis result” wording.
- [ ] There is no claim that the AI/quantum model is clinically validated.

## Demo flow

- [ ] Dashboard loads correctly.
- [ ] User can click Run Demo Analysis.
- [ ] Analysis page shows demo dataset.
- [ ] Results page shows mutation ranking and drug-repurposing shortlist.
- [ ] Report page shows an explainable preview.
- [ ] Architecture page explains workflow.
- [ ] Demo can be completed in under 3 minutes.

## UI/UX quality

- [ ] Uses OncoQ color palette consistently.
- [ ] Sidebar active states are clear.
- [ ] Cards have consistent spacing and radius.
- [ ] Page does not feel overcrowded.
- [ ] Dashboard has a memorable scientific/genomic visual.
- [ ] Typography hierarchy is strong.
- [ ] Contrast is readable.

## Biological credibility

- [ ] Genes and pathways are credible examples.
- [ ] Gene/pathway/drug-class matches are labelled as research hypotheses.
- [ ] The platform explains limitations and validation needs.
- [ ] Evidence categories are shown: Strong, Moderate, Emerging, Exploratory.
- [ ] There are next validation steps.

## AI/quantum credibility

- [ ] “Hybrid quantum” is described as simulated/prototype in Phase 1.
- [ ] No quantum supremacy claim is made.
- [ ] The architecture mentions future benchmarking against classical baselines.
- [ ] Scoring is transparent and deterministic in the prototype.

## Hackathon readiness

- [ ] Prototype supports pitch deck story.
- [ ] Prototype supports system architecture slide.
- [ ] Prototype supports commercial model: paid pilot → SaaS → enterprise licence.
- [ ] Prototype supports Q&A defence.
- [ ] Team can explain what is real, simulated, and future work.
